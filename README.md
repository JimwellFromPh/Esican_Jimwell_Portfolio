## About the Project

This is a personal portfolio website developed using PHP, MySQL, HTML, CSS, and JavaScript. It showcases personal information, skills, education, projects, experience, and achievements.

The website also includes an admin dashboard where the website content can be managed and updated.

## Features

### Public Website
- Home page with personal introduction
- About section
- Skills section
- Education section
- Projects section
- Experience and achievements section
- Contact information and contact form
- Responsive website design
- Dark and light mode

### Admin Dashboard
- Secure admin login and logout
- Dashboard with content statistics
- Manage profile information
- Add, edit, and delete skills
- Add, edit, and delete projects
- Manage education
- Manage experience
- Manage achievements
- View and manage contact messages
- Update website settings and logo
- Change admin password

## Technologies Used

- HTML
