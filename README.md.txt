# Jimwell Esican - Personal Portfolio

## About the Project

This is my personal portfolio website developed to showcase my profile, skills, educational background, projects, experience, and achievements.

The website also includes an admin dashboard where I can manage the content without manually editing the website code.

## Features

### Public Website
- Home page with personal introduction
- About Me section
- Skills section
- Projects showcase
- Education and experience
- Achievements
- Contact form
- Dark Mode and Light Mode

### Admin Dashboard
- Secure admin login and logout
- Dashboard overview
- Profile management
- Skills management
- Projects management
- Education management
- Experience management
- Achievements management
- Messages management
- Website settings
- Change password

## Installation and Setup

1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\`.
3. Open XAMPP Control Panel.
4. Start Apache and MySQL.
5. Open phpMyAdmin at `http://localhost/phpmyadmin`.
6. Create a database named `portfolio`.
7. Import the SQL file located in the `database` folder.
8. Configure your database connection in `includes/config.php`.
9. Open the website:

   `http://localhost/Esican_Jimwell_Portfolio/`

## Admin Access

Open:

`http://localhost/Esican_Jimwell_Portfolio/admin/login.php`

Log in using your administrator credentials.
